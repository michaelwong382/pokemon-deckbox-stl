# Original files by Ashwood

The designer's files for [Pokemon tcg deckbox: Gameboy](https://makerworld.com/en/models/828343), downloaded from MakerWorld. They are kept here unchanged as the reference the remix was built from. License: MakerWorld Standard Digital File License (from the 3MF metadata); check its terms before sharing or selling prints.

| File | Contents |
|---|---|
| Case-bottom.stl | Main body that holds the cards |
| Case-top.stl | Hinged lid with the screen bezel |
| D-Pad.stl | D-pad |
| Button.stl | A/B buttons |
| StartSelect.stl | Start/Select buttons |
| Case-GB.3mf | Bambu Studio project with all parts on one plate and the designer's print profile |
| Pokemon+tcg+deckbox_+Gameboy.zip | The five STLs above in one archive, as downloaded |

## Notes

- The STLs use Y as the up axis, so they import lying on their side in a slicer. The 3MF has them placed correctly.
- The 3MF's part names are in Dutch: *Deksel* is the lid, *KnopAB* the A/B buttons, *KnopStartSelect* the Start/Select buttons.
- Designer's settings: 0.2 mm layers, 2 walls, 10 % infill, tree supports on. The example print was Mountain Dew Yellow PETG.
- Designer's assembly tip for the snap hinges: minimal force, applied steadily.
- The inside is 68 × 35 × 92 mm, which is too short for sleeved cards; that is what the remix fixes.

The D-pad and both button files are still the ones to print with the remix, since the remix does not change them. See the [main README](../../README.md) for the full story.
