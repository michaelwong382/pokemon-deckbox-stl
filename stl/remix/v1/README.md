# Remix, round 1 (superseded)

The first version of the remix, kept for reference. It has the three fixes that make the box usable: 96 mm interior height for sleeved cards, 70 mm interior width, a five-knuckle hinge with a printed pin, and support-free printing. It does **not** have the second-round changes: the lid's screen frame is still a 1.8 mm plate, nothing holds the lid shut, there is no thumb notch, and the lid's inner edges are square.

| File | Print orientation |
|---|---|
| Case-bottom_remix.stl | Upright, open top facing up |
| Case-top_remix.stl | Front face (screen bezel) on the bed |
| Hinge-pin_remix.stl | Lying on one of its flat sides; identical to the current pin |

Print settings and assembly are the same as for the current files in [../v4/](../v4/). Use these only if you specifically want the plain-seam version; otherwise print the current set. Sections 1 to 5 of [improvements.md](../../../improvements.md) describe what this round changed, and sections 6 to 11 describe what the later rounds added on top.
