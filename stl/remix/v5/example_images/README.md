# Example images

Renders of the round-5 files in [../](../) (grey = body, blue = lid, green = pin, coral = D-pad and buttons). Compare a print against these. Views 01 to 20 use the same cameras as [../../v4/example_images/](../../v4/example_images/); views 21 to 23 show the recessed pin head and the test coupons. The engraving in the bottom is shaded darker so it stands out.
