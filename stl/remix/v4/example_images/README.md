# Example images

Renders of the round-4 files in [../](../) (grey = body, blue = lid, green = pin, coral = D-pad and buttons). Compare a print against these. Views 01 to 17 use the same cameras as [../../v3/example_images/](../../v3/example_images/), now with the buttons in their seats; views 18 to 20 are about the buttons. The engraving in the bottom is shaded darker so it stands out.
